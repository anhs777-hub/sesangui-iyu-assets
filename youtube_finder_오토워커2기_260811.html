API 키 설정 (처음 한 번만) ▼
⚠️ API 키가 아직 저장되지 않았어요
🔑 API 키 무료로 발급받는 방법 ▶
  1. Google Cloud 콘솔에 구글 계정으로 로그인하고 새 프로젝트를 만들어요 (이름은 아무거나, 예: youtube-finder)
  2. YouTube Data API v3 페이지에서 파란 "사용" 버튼을 눌러요
  3. 사용자 인증 정보 페이지에서 "+ 사용자 인증 정보 만들기" → "API 키"를 눌러요
  4. 만들어진 키(AIza로 시작)를 복사해서 위 칸에 붙여넣고 저장하면 끝!

⚠️ 키를 만들 때 "애플리케이션 제한 / 키 제한"을 물어보면 반드시 "없음" 그대로 두세요. 웹사이트 제한을 걸면 이 도구에서 키가 작동하지 않아요.

완전 무료예요. 하루 10,000 할당량이 주어지고(키워드 검색 약 100회 분량), 매일 오후 4시(한국시간)에 다시 채워져요. 키는 내 컴퓨터 브라우저에만 저장되고 다른 곳으로 전송되지 않아요.
